# Upload guide — new dashboard

Upload these 5 files to the root of the ScottishFitbaw repo (Add file > Upload files, replace existing):
- index.html   (public page)
- admin.html   (admin page)
- style.css    (new, shared styles)
- app.js       (new, shared code)
- logo.png     (new, small logo)

Do NOT upload data.json from this folder. Your live data.json on GitHub stays exactly as it is.
The old heavy index.html/admin.html are kept in the old/ folder as a backup.

Admin password is unchanged. The admin page now also stamps "Last updated" when you push.
Share card: League Table tab > "Share table" button (works on the public site and in admin).
